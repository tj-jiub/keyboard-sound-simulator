- 적축: freesound.org, "keyboard2.wav" by samchitto (linear switches), Creative Commons 0 — https://freesound.org/people/samchitto/sounds/696040/
- 무음: freesound.org, "Writing In Membrane Keyboard.wav" by SebastianBuitrago+ (membrane keyboard typing), Creative Commons 0 — https://freesound.org/people/SebastianBuitrago+/sounds/626326/
- 타자기: freesound.org, "Olimpia Typewriter clicks" by ikomlino (vintage 1970s Olimpia typewriter), Creative Commons 0 — https://freesound.org/people/ikomlino/sounds/852744/

- Leopold: freesound.org, "Mechanical Keyboard Typing (Treble Version)" by stu556 (Leopold FC660M, Cherry MX Brown switches), Creative Commons 0 — https://freesound.org/people/stu556/sounds/450282/

열 소스 모두 freesound.org에서 라이선스 필터를 "Creative Commons 0"으로 설정해 검색했고, 각 사운드 페이지에 라이선스가 "Creative Commons 0"로 명시된 것을 확인한 뒤 사용했습니다. CC0은 저작자 표시 없이 상업적 이용/수정/배포가 가능합니다. 각 소스에서 서로 다른 타건 순간을 3~4번씩 오려내 50ms 무음으로 이어붙인 스프라이트시트(`sound.wav`)로 가공했습니다.
